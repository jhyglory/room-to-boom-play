# Room to Boom! — playable site

Play the game at https://jhyglory.github.io/room-to-boom-play/.

Build 0.42.0. This repository contains the public runtime only. Anonymous best times and nicknames are shared through the public rankings API. All deployed competitions appear in one combined ranking, with one fastest time per stable player ID; original per-version records and completion receipts are preserved. Old device-only records are not automatically imported. Localhost and GitHub Pages use the same shared rankings API by default. The Python cookie API and database remain available for explicitly isolated development.

Furniture, logos and UI artwork are supplied project assets. Matter.js and font license notices are included.
