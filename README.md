# Room to Boom! — playable site

Play the game at https://jhyglory.github.io/room-to-boom-play/.

Build 0.27.0. This repository contains the public runtime only. Anonymous best times and nicknames are shared through the public rankings API. One best per stage/player; old device-only records are not automatically imported. Localhost and GitHub Pages use the same shared rankings API by default. The Python cookie API and database remain available for explicitly isolated development.

Furniture, logos and UI artwork are supplied project assets. Matter.js and font license notices are included.
